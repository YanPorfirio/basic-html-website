# Basic HTML Website

A multi-page portfolio website built with pure HTML. This project focuses on semantic structure, navigation, basic SEO metadata, and accessible form fields without CSS or JavaScript.

## Pages

- Home
- Projects
- Articles
- Contact

## Project requirements

This project was created based on the roadmap.sh Basic HTML Website project:

https://roadmap.sh/projects/basic-html-website

## Run locally

Open `index.html` in a web browser.
